AI Chatbot Android App

An AI-powered chatbot Android application developed as part of the App Dev With AI Internship 2026 Final Assignment.

About the Project

This application allows users to ask questions and receive AI-generated responses through a simple chat interface.

Features

- Interactive chat interface
- AI-generated answers to user questions
- Simple and user-friendly design
- Android application built using Kotlin

Technologies Used

- Kotlin
- Android Studio
- XML
- OkHttp
- Gemini API

Screenshots

Screenshots of the application will be added here.

How to Run

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Sync the Gradle files.
4. Configure your Gemini API key securely.
5. Run the application on an Android device or emulator.
